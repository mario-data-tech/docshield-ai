# DocShield.ai

DocShield.ai es un motor ligero de descubrimiento de datos sensibles y cumplimiento, orientado a escaneo local de archivos y carpetas.

## Instalación

```bash
git clone [https://github.com/tu-usuario/docshield-ai.git](https://github.com/tu-usuario/docshield-ai.git)
cd docshield-ai
python -m venv .venv
source .venv/bin/activate
pip install -e .
